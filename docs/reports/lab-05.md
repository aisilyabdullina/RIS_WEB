## 1. Цель работы

Связать форму создания заказа (`OrderNew.vue`) с общим массивом в `ordersStore.js`: валидная отправка добавляет запись со статусом `New` и переводит на страницу списка `/`, короткое наименование отклоняется с текстом ошибки под полем, `Enter` не перезагружает страницу, а `F5` очищает память браузера.

## 4. Ответы на вопросы для устной защиты

### 1. Зачем нужен `.prevent` в `@submit.prevent="onCreate"`?
Без него отправка формы по кнопке или `Enter` перезагружает страницу и стирает всё состояние в памяти, включая добавленные заказы. `.prevent` вызывает `event.preventDefault()` и передаёт управление функции `onCreate`.

### 2. Зачем `modelId` нужен модификатор `.number`?
Значение поля из DOM всегда строка (`"2"`). `v-model.number` приводит его к числу, как требует контракт API из ЛР2, где внешний ключ справочника — число.

### 3. Где хранится массив записей?
В модуле `frontend/src/ordersStore.js` как реактивная ссылка `items`. И страница создания, и страница списка импортируют данные из этого одного модуля.

### 4. Почему `F5` очищает новые записи?
В ЛР5 приложение живёт только в оперативной памяти вкладки. При `F5` браузер загружает страницу заново и модуль с начальными данными инициализируется снова. Сервера и базы данных ещё нет.
