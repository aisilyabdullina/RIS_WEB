## 1. Цель работы

В папке `/frontend` основного репозитория поднять клиентское приложение на Vue 3 (JavaScript) и Vite так, чтобы по инструкции из `README.md` открывались три семантически верных экрана (список заказов, создание заказа, вход) на `http://localhost:5173`.

---

## 2. Что реализовано в `/frontend`

1. **Каркас (`Vue 3 + Vite`, JavaScript).** В `vite.config.js` задан порт `5173`. На этапе ЛР3 `App.vue` переключал экраны через реактивную переменную `screen` (`'list'`, `'new'`, `'login'`) и директивы `v-if` / `v-else-if`. В итоговом репозитории этот способ заменён маршрутами ЛР4.
2. **Экран «Список заказов».** Семантическая таблица `<table>` внутри `<main>`. Строки выводятся через `v-for="item in items" :key="item.id"`: `id`, `number`, `title`, `modelId`, `status` (`New`, `InProgress`, `Closed`, `Cancelled`).
3. **Экран «Создание заказа».** Тег `<form @submit.prevent>` с тремя полями из контракта API: `title`, `modelId`, `description`. Каждое поле связано с `<label for="...">`, первое поле (`#title`) получает фокус.
4. **Экран «Вход».** Тег `<form @submit.prevent>` с полями `login` и `password`, подписями `<label>` и кнопкой «Войти».

## 4. Ответы на вопросы для устной защиты

### 1. Зачем нужен Vite, если браузер уже показывает HTML?
Браузер не умеет выполнять однофайловые компоненты `.vue`, в которых объединены `<script setup>`, `<template>` и `<style>`. Vite на лету превращает их в обычные JavaScript и CSS, а ещё мгновенно обновляет страницу при изменении кода.

### 2. Чем `v-for` лучше трёх строк, скопированных вручную?
`v-for` строит строки по массиву данных. Когда записей станет 50 или они начнут приходить с сервера, разметку менять не придётся: Vue сам отрисует нужное число строк и обновит только изменившиеся благодаря `:key="item.id"`.

### 3. Зачем полю нужен `<label>`?
Подпись объясняет человеку, что вводить, даже когда поле уже заполнено; клик по подписи ставит курсор в поле; программы чтения с экрана зачитывают подпись при переходе на поле клавишей `Tab`.

### 4. Почему `node_modules` не кладут в Git?
Папка содержит тысячи файлов и весит десятки мегабайт. В Git хранят лёгкие `package.json` и `package-lock.json`, по ним любой разработчик восстановит `node_modules` командой `npm install`.
