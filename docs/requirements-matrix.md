# Матрица соответствия требований — АИС «КонтрОрдер»

## Связь требований ЛР1 с моделью данных и API

| Требование ЛР1        | Поле или сущность                                   | Запрос                            | Критерий |
| --------------------- | --------------------------------------------------- | --------------------------------- | -------- |
| Создать объект        | `ControllerOrder`, `title`, `modelId`, `description`| `POST /api/orders`                | 1        |
| Назначить исполнителя | `assigneeUserId`                                    | `PATCH /api/orders/{id}/assignee` | 2        |
| Перевести в работу    | `status`                                            | `PATCH /api/orders/{id}/status`   | 3        |

---

**Пояснение:**

- Все три критерия из ЛР1 связаны с полями модели данных (`data-model.md`) и API-запросами (`api-contract.md`)
- Каждая строка матрицы соответствует одному обязательному критерию приёмки
- Если строку нельзя заполнить - значит модель или API нужно доработать
