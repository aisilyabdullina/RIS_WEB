# Архитектура системы — АИС «КонтрОрдер»

## Схема архитектуры

Ниже представлена схема взаимодействия компонентов разрабатываемой информационной системы.

```
┌─────────────────────┐         ┌─────────────────────┐         ┌─────────────────────┐
│                     │  HTTP   │                     │  SQL    │                     │
│   Vue 3 + Vite      │ ──────► │   ASP.NET Core      │ ──────► │   PostgreSQL        │
│   (Клиент)          │         │   (Сервер)          │         │   (База данных)     │
│   localhost:5173    │         │   localhost:5000    │         │   порт: 5432        │
│                     │         │                     │         │                     │
└─────────────────────┘         └─────────────────────┘         └─────────────────────┘
```

архитектура web-ИС семестра

## Описание узлов

1. Vue 3 + Vite (порт 5173): Клиентская часть. Отвечает за отрисовку пользовательского интерфейса (экраны списка заказов, создания заказа, входа в систему) и отправку HTTP-запросов на сервер. Не имеет прямого доступа к базе данных.
2. ASP.NET Core (порт 5000): Серверная часть (Backend). Принимает HTTP-запросы от клиента, проверяет бизнес-правила (валидация, права доступа, статусы), формирует SQL-запросы и возвращает клиенту ответ в формате JSON. Является единственным источником правды о данных.
3. PostgreSQL (порт 5432): Система управления базами данных. Хранит сущности ControllerOrder, ControllerModel и User в нормализованном виде (3НФ). Отвечает только на запросы от сервера ASP.NET Core.

## Пример запроса

**Действие: Создание нового заказа на контроллер.**

Метод: POST

Путь: <http://localhost:5000/api/orders>

Тело запроса (JSON):

```
{
  "title": "Контроллер для линии фасовки",
  "modelId": 5,
  "description": "10 шт., интерфейс Modbus RTU, исполнение для цеха с повышенной температурой"
}
```

Код ответа: `201 Created`

Тело ответа (JSON):

```
{
  "id": 17,
  "number": "ORD-2026-042",
  "status": "New",
  "modelId": 5,
  "assigneeUserId": null
}
```
